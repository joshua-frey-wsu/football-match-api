# football-match-api
This Project uses the AI from defang generate to build a node.js project that displays a table of the champions league matches from [football-data.org's](https://www.football-data.org/) API.

The project is deployed using defang compose up and can be accessed on [https://joshua-frey-wsu-service1--3000.prod1a.defang.dev/](https://joshua-frey-wsu-service1--3000.prod1a.defang.dev/).

If you use a domain name, specify in the compose.yaml file and use defang cert generate command for the new dns.
